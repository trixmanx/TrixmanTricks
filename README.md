# TrixmanTricks
Дебаффы для стримов. Зрители пишут в чат YouTube/Twitch → программа находит название дебаффа в сообщении → активирует дебафф у тебя на компьютере (если зрителю повезёт). За донат дебафф выполняется без проверки на везение и без очереди. Работает в любой игре (наверное, я ж не проверял прям все игры).
